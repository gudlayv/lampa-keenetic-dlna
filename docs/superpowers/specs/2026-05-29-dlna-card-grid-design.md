# Дизайн: переход dlna.js со списка на карточную сетку

Дата: 2026-05-29
Статус: дизайн на ревью
Файл: `plugins/dlna.js`

## Цель

Заменить вертикальный список строк (`.dlna-row`) на сетку постеров-карточек,
как нативно делает LAMPA. Мотивация — лучше охватить всю библиотеку на экране
ТВ: больше элементов сразу, описательная мета уходит под постер текстом, а не
в длинную строку.

## Решения (зафиксированы в брейнсторме)

1. **Раскладка** — сетка постеров вместо списка. Постер **чистый** (вариант B):
   никаких оверлеев-метаданных поверх картинки. Рейтинг/качество/год/тип — текстом
   под постером.
2. **Плотность** — 5 карточек в ряд. Ширина задается в `em` (адаптив под шрифт/экран),
   ориентир — нативные `~12.75em`, постер 2:3 через `padding-bottom: 150%`.
3. **Сериалы** — в сетке **одна карточка на сериал** (группировка по show поверх
   текущей по сезонам). Тап → экран выбора сезона; если сезон один — сразу серии.
   На экране выбора сезона — **посезонные постеры TMDB** (fallback на общий постер
   сериала, если посезонного нет).
4. **Серии** — остаются **списком** (16:9-кадр + название + описание), не сеткой.
5. **Папки** (не-сериалы) — карточка с иконкой папки.
6. **Кнопка «Назад»** — строкой над сеткой (не карточкой).

## Подход к реализации

**Выбран: кастомные тайлы** (рефактор существующих row-билдеров в tile-билдеры).

Отклоненные альтернативы:

- **Нативный `Lampa.Card`** — дает «бесплатно» маркеры/lazy/единый фокус, но:
  (а) строится один раз из готового TMDB-объекта, не поддерживает наш паттерн
  «создать плейсхолдер → дозаполнить по приходу TMDB»; (б) нативный фокус завязан
  на LAMPA-стили со scale/transition, что лагает на Tizen WebKit 76 (в плагине это
  намеренно обходится, см. `injectStyles`); (в) моделирует один фильм/сериал —
  папки и агрегат-карточки в него не ложатся.
- **CSS-only (только сменить контейнер на flex-wrap)** — минимум кода, но текущий
  DOM строки (flex: постер слева + инфо справа) не превращается в постер-тайл;
  пришлось бы бороться с инлайн-стилями. Не достигает чистой карточки «постер
  сверху, текст снизу».

## Архитектура карточки (tile)

```
.dlna-card                     (selector, width ~ grid/5, data-hash для прогресса)
  .dlna-card__poster           (2:3, border-radius, чистая картинка; иконка-плейсхолдер при загрузке)
  .dlna-card__progress         (тонкий бар ПОД постером, только если percent>0)
  .dlna-card__title            (1-2 строки, line-clamp)
  .dlna-card__meta             (год · тип · ★рейтинг  |  «N сезонов · M серий»  |  качество)
```

- **Фокус** (Tizen-safe): рамка через `box-shadow`/`::after` border, **без**
  transition/scale. Никакого осветления всей плитки — фокус на постере.
- **Просмотрено (≥80%)**: маркер `✓` в строке меты (не оверлеем на постере).
- **Прогресс (0<percent<80)**: тонкий бар `.dlna-card__progress` под постером.
- Постер грузится с плейсхолдер-иконкой; по приходу TMDB подменяется background-image
  (как сейчас в `applyTmdbMovie`/`applyTmdbSeries`).

## Модель данных

Текущий конвейер: `groupEpisodes(rawEntries)` (dlna.js:396) группирует по `show|season`
→ по виртуальной entry **на каждый сезон** (`isVirtualSeries`).

Добавляется слой группировки по сериалу:

- **`groupShows(entries)`** — поверх `groupEpisodes`: виртуальные сезоны одного `show`
  сворачиваются в одну агрегат-entry `{ isVirtualShow, show, seasons: [{season, episodes}],
  totalEpisodes }`. Фильмы и папки проходят как есть.
- Карточка сериала: TMDB tv-поиск (`tmdbSearch(show, null, 'tv', …)`), постер +
  рейтинг + годы; мета — `«N сезонов · M серий»`, либо `«M серий»` если сезон один.
- Карточка фильма: как сейчас (`parseFilename` → `tmdbSearch('movie')`), мета —
  `год · фильм · ★рейтинг`, плюс качество/длительность если есть локально.

## Навигационный стек

Текущие виды стека: корень/папка (rows), `kind:'episodes'` (серии).

Добавляется `kind:'seasons'` — экран выбора сезона:

- Открывается тапом по карточке сериала, **только если сезонов > 1**.
  Если сезон один — сразу `push({kind:'episodes', payload: серии})` (как сейчас).
- Рендерит карточки сезонов с посезонными постерами. Постер сезона тянется через
  существующий `tmdbSeason(tvId, seasonNum, cb)` (dlna.js:998) → `poster_path` сезона;
  при отсутствии — общий постер сериала.
- Тап по сезону → `push({kind:'episodes', payload: серии этого сезона})`.

## Поток данных

1. `openCurrent` → `browse`/индекс → `renderEntries(rawEntries)`.
2. `renderEntries`: если не экран серий — `groupShows(groupEpisodes(rawEntries))`;
   иначе серии как есть.
3. Для каждой entry → `renderCard()` создает плитку с плейсхолдером, навешивает
   `hover:focus`(→`scroll.update`) и `hover:enter`.
4. Async TMDB резолвится per-card → подменяет постер/заголовок/мету/`data-hash`
   (как в текущих `applyTmdb*`).
5. `hover:enter`:
   - папка → `stack.push`, `openCurrent`;
   - сериал, сезонов >1 → `stack.push({kind:'seasons'})`;
   - сериал, 1 сезон → `stack.push({kind:'episodes'})`;
   - фильм → `playEntry`.
6. Возврат из плеера (`Player.listener('destroy')`) → `refreshProgress()` обновляет
   бары/✓ на видимых `.dlna-card[data-hash]` и `.dlna-row[data-hash]` (серии).

## Обработка ошибок / краевые случаи

- **Нет постера TMDB** — плитка остается с иконкой-плейсхолдером, текст-мета все
  равно показывается.
- **TMDB не найден** — заголовок = техническое имя файла/папки, мета = «TMDB: не найдено»
  (как сейчас в строках).
- **Посезонного постера нет** — fallback на общий постер сериала.
- **Длинные названия** — `line-clamp` 2 строки в `.dlna-card__title`.
- **Состояния `no_proxy` / ошибка Browse / пустая папка** — те же сообщения, что и
  сейчас, рендерятся над/вместо сетки (не ломают грид).
- **Сериал, но в библиотеке лишь часть сезонов** (напр. только S3) — `groupShows`
  агрегирует только присутствующие; «1 сезон» → сразу серии.

## Тестирование / верификация

Юнит-тестов в проекте нет; проверка — визуальная.

- **Автоматическая раскладка**: `node tools/browse.js --plugin plugins/dlna.js`
  инжектит плагин в lampa.mx (Playwright headless) и снимает скриншот в `shots/`.
  Проверяем: грид рисуется, 5 в ряд, фокус-рамка, плейсхолдеры, отсутствие
  pageerror в логе.
- **Ручная с реальными данными** (через `serve.py`-прокси + DLNA Кинетика, на
  устройстве/headed): навигация пультом по сетке; дозаполнение TMDB; карточка
  сериала → выбор сезона (посезонные постеры) → серии списком; пропуск выбора
  для односезонных; папки; прогресс-бар и ✓ после возврата из плеера; «Назад».
- **Регрессия**: история LAMPA, playlist сезона в плеере, `data-hash`-прогресс
  на main TMDB-карточке — поведение не меняется (трогаем только рендер).

## Вне scope

- Не меняем серии (остаются списком), плеер, Transmission-интеграцию, прокси.
- Не вводим нативный `Lampa.Card`.
- Поиск/доп. фильтры карточек — не трогаем (фильтр «Все/Фильмы/Сериалы/Папки» как есть).

## Открытые мелочи на ревью

- Точное место маркера «просмотрено» и тонкого прогресс-бара (под постером vs
  префикс в мете) — уточнить при первом скриншоте.
- Прогресс на агрегат-карточке сериала: в MVP не показываем (прогресс живет на
  сериях). При желании — позже добавить точку «есть незавершенные».
