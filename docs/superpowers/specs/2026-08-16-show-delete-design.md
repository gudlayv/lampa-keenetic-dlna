# Удаление сериала разом через Transmission — дизайн

Дата: 2026-08-16
Статус: согласовано

## Проблема

Удаление с диска есть только на карточках фильмов (long-press → поиск раздачи
по имени файла → `torrent-remove` + `delete-local-data`). Для сериалов
удаления в плагине нет вообще — приходится удалять файлы по одной серии через
web-UI роутера, а потом вручную вычищать раздачу из Transmission.

## Решение (зафиксировано с пользователем)

Long-press OK на агрегат-карточке сериала → **удалить весь сериал разом**:
найти все относящиеся раздачи Transmission, подтвердить списком, удалить
одним действием вместе с файлами. Выбор отдельных раздач/сезонов — вне scope.

## Архитектура

### UI

- `renderShowCard`: `card.on('hover:long', …)` → `Lampa.Select.show` с
  пунктами «Удалить сериал с диска» / «Закрыть» — зеркально
  `renderMovieCard` (`hover:long` и `hover:enter` не конфликтуют, Lampa
  шлет одно из двух).
- Transmission не настроен (`trAddr()` пуст) → Noty «Transmission не
  настроен — удаление недоступно», как у фильмов.

### Поиск раздач: `findTorrentsForShow(showEntry, list)`

- Чистый хелпер рядом с `findTorrentForFile`.
- Берет все серии `showEntry.seasons[].episodes[]`, для каждой зовет
  существующий `findTorrentForFile(ep.title, list)`, собирает уникальные
  раздачи.
- Возврат `{ torrents: [{id, name}], matchedEpisodes: M, totalEpisodes: K }`.
- Матчинг остается консервативным (границы слов, порог длины) — лучше не
  найти, чем удалить чужую раздачу.

### Подтверждение

- `Lampa.Select`: заголовок «Удалить "Название" с диска?», пункты:
  - «Да, удалить N раздач» — subtitle с перечнем имен раздач;
    если `M < K` — приписка «покрыто M из K серий, остальное — через
    web-UI роутера» (удалить найденное даем);
  - «Назад».
- Раздач не нашли вовсе → Noty «Не нашел раздач сериала в Transmission —
  удалить можно только через web-UI роутера».

### Удаление

- Один RPC: `TransmissionClient.remove(ids, true)` — метод уже принимает
  массив id, все раздачи уходят одним `torrent-remove` с
  `delete-local-data: true`.
- Успех → Noty «Удалено N раздач — записи пропадут после рескана MiniDLNA
  (5–10 минут)».
- Ошибка → Noty с reason (`auth|network|forbidden|server|rpc|parse`),
  как в существующем удалении.

## Границы

- Удаление только с агрегат-карточки сериала в сетке; экран серий и
  карточки сезонов не трогаем.
- Существующее удаление фильмов и вкладка «Закачки» не меняются.
- Частичный выбор раздач — вне scope (решение пользователя: весь разом).

## Тестирование

- Юнит на `findTorrentsForShow` в существующий каталог регресс-тестов:
  сезон-пак (много серий → одна раздача), серии отдельными раздачами,
  частичное покрытие (M < K), ничего не найдено.
- End-to-end на живом Transmission/DLNA (memory: verify-against-live-dlna):
  сериал с сезон-паком → long-press → подтверждение → раздача ушла из
  Transmission, файлы с диска, после рескана сериал пропал из «Все».

## Версия

`PLUGIN_VERSION` → `0.15.0` отдельным коммитом `v0.15.0: …` после `0.14.0`
(озвучка) — два независимых user-facing изменения (memory:
bump-plugin-version).
