# Запоминание озвучки и субтитров между сериями — дизайн

Дата: 2026-08-16
Статус: согласовано

## Проблема

При переключении серии в плеере (автопереход плейлиста или ручной выбор)
выбранная аудиодорожка сбрасывается на дефолтную, и озвучку приходится
выбирать заново на каждой серии. То же с субтитрами.

## Решение (зафиксировано с пользователем)

1. **Помнить выбор по сериалу навсегда** — в `Lampa.Storage`, а не только на
   время плейлиста: при возврате к сериалу через день озвучка
   восстанавливается сама.
2. **Субтитры — той же механикой** (включая выбор «выключены», если его
   удастся перехватить).
3. **Реализация внутри `TrackRelabel`** (подход 1): выбор дорожки в
   перерисованном меню уже проходит через наши сеттеры — там запоминаем,
   после релейблинга восстанавливаем. Отдельного модуля поверх нативных
   `audioTracks` и гибрида не делаем.

## Архитектура

### Хранение

- `Lampa.Storage`, ключ `dlna_track_memory`: map
  `ключСериала → { audio: {label, language, index}, subs: {label, language, index} | {off: true}, time }`.
- Ключ сериала — TMDB id карточки (`card.id`), fallback — нормализованное
  название (`normKey`). Для фильмов механизм работает так же (повторный
  просмотр), отдельной ветки нет.
- Лимит ~50 записей: при превышении вытесняется запись с минимальным `time`.

### Ключ при автопереключении серий

`Player.listener('start')` при переходе плейлиста приходит **без `card`** —
в элементах плейлиста только `title/url/timeline`. Поэтому:

- при старте с `card` (все запуски идут через `playMovie`) вычисляем ключ и
  сохраняем в модульную переменную `TrackRelabel`;
- последующие старты того же плейлиста (без `card`, но `isOurMedia`)
  переиспользуют сохраненный ключ;
- в элементы плейлиста ничего не добавляем — `data.playlist` уходит внешним
  плеерам через query, раздувать нельзя.

### Запоминание выбора

- В сеттере `enabled` аудио-элемента и `mode` саб-элемента (внутри
  `setTracks`/`setSubs`) — записываем `{label, language, index}` выбранной
  дорожки в Storage под текущим ключом, `time = Date.now()`.
- Запоминаем **только явный выбор пользователя**; дефолтную дорожку при
  старте не записываем.
- «Субтитры выключены»: если пункт «Отключить» панели дергает наши сеттеры —
  пишем `{off: true}`; если нет (проверяется на устройстве) — off не
  запоминается, остальное работает.

### Восстановление

- В `setTracks()`/`setSubs()` после построения списка, **перед**
  `Lampa.PlayerPanel.setTracks()/setSubs()`: если для ключа есть запись —
  ищем дорожку каскадом: точный `label` (имя студии) → `language` → `index`.
- Нашли — включаем underlying-дорожку той же логикой, что в сеттере
  (все `enabled/selected = false`, выбранной — `true`), и ставим `selected`
  элементу меню, чтобы галка была правильной сразу.
- Идемпотентно: `setTracks` зовется и с `canplay`, и по событию `tracks`,
  и по приходу ffprobe — повторное применение того же выбора безвредно.
- Матч-функция выносится в чистый хелпер (сохраненный выбор + список
  дорожек → индекс или null) — на нее юнит-тест.

## Границы и ошибки

- webOS-путь (`setWebosTracks`/`setWebosSubs`) не трогаем — выбор там
  нативный, у пользователя Tizen.
- Нет ffprobe/прокси → меню не перерисовано → фича молча не работает
  (как и релейблинг сейчас).
- Ничего не совпало (другой релиз без этой студии) → дефолтное поведение,
  без ошибок и Noty.
- Storage недоступен/бит — try/catch, no-op.

## Тестирование

- Юнит на хелпер сопоставления (label-матч, language-фолбэк, index-фолбэк,
  нет матча) — в существующий каталог регресс-тестов.
- End-to-end на телевизоре с живым DLNA (memory: verify-against-live-dlna):
  выбрать озвучку → автопереход серии → озвучка та же; перезапуск LAMPA →
  продолжить сериал → озвучка та же.
